# HI HOME logo assets

- `hi-home-logo-original.png`: original 120 × 150 transparent PNG extracted from https://hihomerd.com/wp-content/uploads/2022/12/logo-hihome.png.
- `hi-home-logo-4k.png`: reconstructed high-resolution derivative, 3072 × 3840, transparent RGBA. AI-assisted reconstruction from the small original, then removal of the black export matte, flat-color cleanup and proportional resampling. It is not an original brand master or an exact vector tracing.

The 4K derivative is used by the header and footer through Next Image responsive optimization. CSS preserves the 4:5 aspect ratio and the original on-page footprint. Original file retained for reference.

Prepared 2026-09-30. Preparation utility: `scripts/prepare-brand-logo.mjs`.
